# survey-service-007: 재질문 단계와 설명 요청 흐름이 계약 설명과 브리프에서 다르게 읽힌다

## 상태
요청(2026-11-10, survey-service 작업자). 대상: 헤드.

## 무엇이 어긋나나(읽어서 확인한 것)
- `ActionExtractionRules` 설명은 '재질문 단계(문진 끝에 한도로 비운 문항을 다시 묻는 단계)에서는 서비스가 정한 순서가 next_item 보증보다 우선한다'고 쓴다.
- `ReaskLimit`·브리프·`v7-flow-resolutions.md` 는 한도에 닿으면 문항을 건너뛰고 끝이라고 쓴다. 문진 끝에 다시 묻는 단계는 흐름 어디에도 정의되어 있지 않다.

## 영역이 지금 한 것
재질문 단계를 만들지 않았다(영역 ADR 0012). 건너뛴 문항은 결과에 빈칸 원인 REASK_LIMIT 로 남는다.

## 요청
재질문 단계가 제품에 있는지 정해 달라. 있다면 그 흐름(언제, 몇 번, 어떤 요청)을 계약과 `design.md` 3절에 정의하고, 없다면 `ActionExtractionRules` 의 해당 문장을 지워 달라.

## 하지 않은 것
계약과 생성물을 영역에서 고치지 않았다(계약은 동결이고 계약 타입은 생성 명령으로만 만든다).
