# v7 흐름 목록의 충돌·공백 정리 (flows.md 3절 C01~C25)

정리 규칙:
- 사용자 결정(U·L 번호)이 헤드 판단(D 번호)보다 우선한다.
- 헤드 결정끼리는 최신 결정이 이긴다.
- 근거가 없으면 헤드가 표준에 따라 판단하고 ADR로 남긴다.
- 운영 정책, 환자 안전, 제품 범위, 외부 공개는 사용자에게 묻는다.

**사용자 결정(2026-11-10):**
- 되묻기 한도는 처음 질문 1회에 되묻기 2회다(답을 피하거나 제대로 답하지 않는 상태를 막는 장치).
- 사용자 말은 직전 화면 질문에 대한 답으로 읽고, 모호하면 되묻는다.
- 사용자 발화 한 턴의 상한은 300자다. 근거는 학습 데이터 36,145행의 발화 길이(중앙 28, 99% 75, 최대 140자)이고, 상한은 최대의 약 2배다.
- 질문의 뜻·대상을 묻는 되물음은 되묻기 한도에 세지 않는다. 한 문항에서 설명 요청만 3번 이어지면 직원 도움을 안내한다.
- C10, C16, C20, C25는 위 표와 같다.
