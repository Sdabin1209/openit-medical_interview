# 0005. 감시: 경보 수신과 영역 지표

## 상태
승인(2026-11-10, platform 작업). 리포 ADR 0014의 "Alertmanager 는 기본 구성에 넣지 않는다, 수신처는 설정으로 둔다"를 구체화한다(수신처는 여전히 설치 설정이다).

## 맥락
브리프: "각 영역 /metrics 수집, 인증서 만료 경보, 서버 전체 중단 경보 수신처는 설정." 계약 `AlertReceiverUrl`(https 웹훅 또는 mailto)이 수신처 설정이다. 서버 전체가 멈추면 서버 안의 감시도 멈춰 경보를 보낼 수 없다(D10: 서버 밖 감시).

## 결정
- **영역 지표:** Prometheus 작업 `openit-areas` 가 노출 선언이 있는 서비스마다 `https://<서비스>:<OPENIT_SERVICE_PORT>/metrics` 를 읽는다. 서비스 인증서는 신뢰 목록으로 검증한다. 대상 파일은 `./deploy` 가 노출 선언에서 만들고 Prometheus 가 파일 변경을 스스로 읽는다.
- **경보:** 기존 두 규칙(리프 만료 24시간 전, TLS 점검 실패)에 `OpenitAreaDown`(영역 지표를 5분 넘게 못 읽음)과 `OpenitManualCertificateExpiresSoon`(사람이 갈아 끼우는 `organization` 입구 인증서가 30일 아래, 2592000초)을 더했다. 30일은 근거가 되는 표준이 없는 선택값이고 측정하지 않았다. `./deploy ca status` 의 기준(`ORGANIZATION_CERT_WARN_MINUTES`)과 같은 값이며 시험이 두 곳을 맞춰 본다.
- **수신:** Alertmanager(Apache-2.0, 이미지 digest 고정)가 경보를 `OPENIT_ALERT_RECEIVER_URL` 로 보낸다. 웹훅 주소는 설정 파일이 아니라 파일(`url_file`)로 준다(주소의 경로에 토큰이 든 경우가 많다, D84). `mailto:` 는 SMTP 서버(`OPENIT_ALERT_SMTP_SMARTHOST`)가 있어야 한다(변경 요청 platform-001). 수신처가 비어 있으면 어디로도 보내지 않고 `./deploy doctor` 가 알린다.
- **서버 중단:** 늘 켜져 있는 경보 `Watchdog`(`vector(1)`)를 `OPENIT_ALERT_HEARTBEAT_INTERVAL`(기본 1분)마다 같은 수신처로 다시 보낸다(dead man's switch). 수신처가 이 신호가 끊기는 것으로 서버 전체의 중단을 알아차린다.
- **설정 검증:** `promtool test rules`(규칙 시험)와 `promtool check config`, `amtool check-config` 를 `./deploy doctor` 가 돌린다.

## 왜
- 서버 안의 감시는 서버가 멈추면 말이 없다. 끊김을 수신처가 알아차리게 하는 생존 신호 방식은 Prometheus·Alertmanager 가 문서에서 권하는 표준 패턴(Watchdog)이다.
- 수신처 종류(메일, 메신저)는 설치처마다 달라서 하나만 고르지 않고 계약의 두 형식만 받는다.

## 검토한 대안과 버리는 이유
- **서버 안에서 서버 중단을 감지:** 불가능하다(서버가 멈추면 감지기도 멈춘다).
- **외부 감시 서비스를 구성에 넣기:** 설치처가 고르는 서버 밖 도구다. 이 구성은 신호를 보낼 뿐이다.
- **웹훅 주소를 alertmanager.yml 에 직접:** 토큰이 설정 파일에 남는다.

## 결과
- **얻는 것:** 영역 지표 수집과 경보 설정이 노출 선언을 따라가고, 수신처가 생존 신호를 받는다. 샌드박스에서 영역 3곳의 지표 수집과 Watchdog 발화를 확인했다.
- **감수하는 것:** 수신처로 실제 전송은 시험하지 않았다(수신처가 서버 밖이다). 웹훅 수신처의 TLS 는 Alertmanager 가 시스템 신뢰 저장소로 검증하므로 사설 CA 인증서 수신처는 쓸 수 없다. Envoy 자신의 지표는 수집하지 않는다(관리 인터페이스를 루프백에만 연다).

## 되돌리는 조건
알림 수신처가 둘 이상 필요해지면 수신처 목록을 계약에서 받는다. 영역이 다른 서버로 나뉘어 직접 닿지 못하면 수집 방식을 새 ADR 로 정한다.
