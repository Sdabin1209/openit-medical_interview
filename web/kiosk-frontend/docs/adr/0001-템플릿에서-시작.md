# 0001. 템플릿에서 시작

## 상태
승인

## 맥락
영역 구조는 루트 ADR 0003이 정한다. 새 영역은 `tools/new-area`로 `templates/web`에서 만든다.

## 결정
이 영역은 템플릿 구조 그대로 시작한다. 구조를 벗어나는 선택은 이 폴더의 ADR로 새로 남긴다.

## 왜
구조가 모든 영역에서 같아야 읽는 사람이 한 번만 익힌다(루트 ADR 0003).

## 검토한 대안과 버리는 이유
영역마다 자유 구조: v1~v6의 문제가 반복된다.

## 결과
같은 명령(`npm test`, `npm run lint`)이 통한다.

## 되돌리는 조건
루트 ADR 0003이 대체되면 따른다.
