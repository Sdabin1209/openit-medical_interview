# 0009. 노출 선언(exposure.json)과 나가는 호출 선언

## 상태
승인(2026-11-11, model-runtime 영역 작업자). 계약 9.0.0 `Exposure`·platform-003 에 영역을 맞춘다.

## 맥락
이미지 라벨 `io.openit.exposure` 의 원본은 영역 폴더의 `exposure.json`(계약 `Exposure`)이다. platform 은 노출 선언 × 계약 작업의 `security` 로 입구 라우트를 만들고, 허용 작업이 없는 접두어는 시작하지 않는다(platform ADR 0003). 경로가 요구하는 역할의 정본은 작업 `security` 이고 `ExposureRoute` 는 역할 칸이 없다.

## 결정
- `routes`(작업 일곱 개를 접두어로 덮는다):
  - 영역 사이(survey-service): `POST /v1/extractions`, `POST /v1/responses`, `GET /v1/model-status` → `MACHINE_TOKEN`
  - 사람(admin-console): `GET /v1/model-status`, `GET /v1/model-packages`(목록과 digest 읽기), `POST /v1/model-activations`, `POST /v1/model-rollbacks` → `HUMAN_OIDC`
  - `/healthz`·`/readyz`·`/metrics` 는 입구로 내보내지 않으므로 선언하지 않는다.
- `egress`: `["platform"]`. 서비스 이름 `platform` 은 토큰 발급자(OIDC 발급자의 호스트·포트, JWKS)로 나가는 터널이다(계약 `EgressTarget` 설명).
- **레지스트리 접근은 서비스 이름으로 선언하지 못한다.** 레지스트리는 설치처 호스트(`OPENIT_REGISTRY_URL`)이고 같은 서버의 platform 이 아닐 수도 있다. `ExternalEgressTarget`(호스트·포트)는 설치처 값이라 이미지 라벨에 못 박을 수 없다. 헤드 결정([변경 요청 model-runtime-005](../../../../docs/change-requests/model-runtime-005.md)): 레지스트리 egress 는 deploy 가 설치 설정(`OPENIT_REGISTRY_URL`)에서 읽어 이 서비스의 egress 에 더한다. 영역 코드와 `exposure.json` 은 바꾸지 않는다. 이름 표(`OPENIT_HOSTS_TABLE_FILE`)가 있으면 그 이름을 게이트웨이가 풀 수 있어야 한다.
- 시험이 계약 `openapi/model-runtime.yaml` 에서 작업마다 허용 대상(`oidc`, `machine_token`)을 읽어 노출 선언과 어긋나지 않는지, 모든 경로 접두어가 허용 작업을 하나 이상 여는지 본다(platform 의 규칙을 같은 방식으로 재현).

## 왜
- 역할을 두 곳에 쓰면 어긋난다(platform-003). 작업 `security` 가 정본이다.
- `MACHINE_TOKEN` 은 같은 서버의 영역 사이 호출용이고 `EXTERNAL_MACHINE_TOKEN` 은 `area_mtls` 가 함께 있는 요구에는 열리지 않는다(`gateway.py`). survey-service → model-runtime 호출의 작업 `security` 가 `area_mtls` 와 `machine_token` 을 함께 요구하므로 `MACHINE_TOKEN` 이 맞다.

## 검토한 대안과 버리는 이유
- 접두어 `/v1` 하나로 선언: 작업마다 대상이 다른데(사람 전용 작업에 `MACHINE_TOKEN` 도 열림) 최소 권한이 아니다. 버린다.
- 레지스트리를 `platform` 으로 선언: `platform` 의 계약상 뜻은 토큰 발급자다. 레지스트리가 platform 에 있다는 것이 설치처 사실이라 영역이 단정하지 않는다.

## 결과
- 얻는 것: 라우트와 허용 대상이 계약에서 나온다. 선언이 시험으로 고정된다.
- 감수하는 것: 레지스트리 egress 가 deploy 몫이다(확정). 이 선언을 platform 의 실제 `gateway.plan` 으로는 돌려 보지 않았다(영역 시험이 같은 규칙을 재현한다).

## 되돌리는 조건
계약이 레지스트리를 가리키는 egress 이름을 만들면 `exposure.json` 에 더한다.
